Versi 5.0 Mei 2026 Semua bisa diatur langsung dari aplikasi
"Nggak perlu edit file manual lagi! Nama toko, logo, QRIS, folder data, sampai icon aplikasi — semuanya bisa diatur langsung dari dalam app. Setup 5 menit, langsung jalan."
  • Panel Pengaturan Toko — Tab baru khusus admin untuk atur semua konfigurasi toko: nama, tagline, alamat, nomor WA, dan lebar kertas struk (58mm/80mm). Semua langsung tersimpan tanpa perlu restart.
  • Logo Toko di Struk — Upload gambar logo (PNG/JPG) yang tampil di header struk thermal. Pilih file langsung dari file browser, pratinjau tampil seketika.
  • Ganti Icon Aplikasi — Icon di titlebar dan taskbar Windows sekarang bisa diganti dari dalam app (format .ico atau .png). Perubahan langsung aktif tanpa perlu restart — tidak perlu reinstall.
  • Setup QRIS Lebih Mudah — Tempel konten QRIS statis, langsung muncul preview QR Code-nya. Ada tombol "Uji Cetak" untuk test cetak slip QRIS ke printer sebelum dipakai di kasir.
  • Preview Struk Dummy — Simulasi tampilan kertas struk berdasarkan setting toko saat ini. Bisa cek format sebelum cetak sungguhan — hemat kertas!
  • Pilih Folder Data Sendiri — Folder penyimpanan transaksi dan order sekarang bisa diubah lewat UI. Cocok untuk yang mau simpan data di USB, NAS, atau OneDrive.
  • Perbaikan Teknis Penting — Fix icon window yang kembali ke default setelah install. Fix QRIS tidak terbaca karena file .env tidak ditemukan di folder instalasi. Semua konfigurasi sekarang disimpan di satu lokasi yang pasti bisa diakses.

Versi 4.0 Mei 2026 Update aman, data nggak pernah hilang
"Mulai versi ini, kamu bisa update aplikasi kapan saja — data transaksi, akun, dan pengaturan semuanya terjaga otomatis. Nggak perlu takut lagi kalau ada versi baru!"
  • Backup Otomatis Setiap Startup — Setiap kali aplikasi dibuka, semua data (transaksi, order, akun) langsung di-backup otomatis. Maksimal 10 backup tersimpan, yang lama dihapus sendiri.
  • Migrasi Data Antar Versi — Update ke versi baru? Aplikasi otomatis menyesuaikan struktur data lama ke format terbaru. Kamu tinggal klik Next–Next–Finish, sisanya urus sendiri.
  • Restore Backup 1 Klik — Kalau ada yang tidak beres setelah update, admin bisa langsung restore ke kondisi sebelumnya dari panel Database Settings. Data kembali seperti semula dalam hitungan detik.
  • Versioning Ganda (App & Data) — Aplikasi sekarang melacak dua versi: versi app (tampilan/fitur) dan versi data (struktur file). Keduanya bisa berkembang secara independen tanpa konflik.
  • Startup Validation — Saat pertama buka, app otomatis cek kondisi data dan konfigurasi. Kalau ada yang perlu diperhatikan, langsung muncul notifikasi dengan panduan solusinya.
  • Update Lebih Cepat & Aman — Proses update sekarang lebih terstruktur: backup dulu → migrasi data → validasi → baru buka app. Urutan ini menjamin data tidak pernah rusak meski listrik mati di tengah proses.

Versi 3.0 April 2025 Versi keyboard-first pertama
"Kami dengar masukan kalian — sekarang semua bisa dikerjain tanpa harus pegang mouse!"
  • Sistem Login & Hak Akses — Admin dan Kasir punya akses yang berbeda. Kasir cukup fokus ke transaksi, admin yang atur settings-nya.
  • Operasi Full Keyboard — Dari input produk, harga, qty, sampai bayar — semua bisa lewat Tab, Enter, dan shortcut. Nggak perlu klik klik lagi!
  • Shortcut Cepat Kasir — Ctrl+I uang masuk, Ctrl+U keluar, Ctrl+P cetak, F2 nominal, F3 keterangan.
  • Tampilan Dashboard Baru — Navigasi tab lebih rapi, profil user di pojok kanan atas, ubah password bisa langsung dari menu tanpa keluar halaman.
  • Mode Custom Order — Produk nggak ada di katalog? Ketik nama, harga, qty — langsung masuk keranjang. Alur Tab → Tab → Enter selesai dalam hitungan detik.
  • Shortcut Pembayaran — Di layar bayar: tekan 1 untuk Tunai, 2 untuk QRIS, Enter konfirmasi, Esc batal.
  • Koneksi Database Opsional — App tetap jalan meski tanpa MySQL. Data transaksi tersimpan lokal di JSON, MySQL hanya untuk sinkronisasi tambahan.

Versi 2.0 Februari 2025 Lebih pintar, lebih cepat
"Versi ini kami fokuskan ke kecepatan transaksi dan kemudahan input produk dari Shopify."

  • Rekap Kas — Catat uang masuk dan keluar kas. Cocok buat pembukuan harian yang simpel tanpa ribet.
  • Pengaturan Printer — Pilih printer dari daftar yang terdeteksi, test cetak bisa langsung dari settings.
